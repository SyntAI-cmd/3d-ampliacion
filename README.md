# Planta El Pollito Casero

- `plano-ampliacion-original.html`: el plano 2D/3D del anteproyecto, sin cambios.
- `disenador-planta.html`: diseñador editable. Permite agregar, mover, girar y cambiar las medidas de cámaras, salones, balanzas, máquinas de faena, calles, camiones y personal, ampliar el predio, ver el resultado en 3D, guardar diseños y exportar PNG o JSON.
